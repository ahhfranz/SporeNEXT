# Spore NEXT Launcher

Spore NEXT is an open-source mod manager for **Spore: Galactic Adventures**. It simplifies downloading, installing, and managing mods using [Spore Mod Loader / Spore Mod Manager](https://github.com/Rosalie241/SporeModLoader) through a user friendly and easy to use interface built with Electron.js.
 
---

### Requirements

- **Windows 10** / **Windows 11**.
- A legitimate copy of **Spore: Galactic Adventures** (Steam, GOG, or EA App).
- Only **one installation of the game** on your PC. The launcher detects the game location through the Windows Registry, and multiple installations may cause conflicts. (Also, do not install the game from EA App if you already have it installed from Steam or GOG).
- **Spore Mod API is not supported**. Spore NEXT uses Spore Mod Loader and Spore Mod Manager to install, uninstall, update and manage mods. Both tools cannot be installed or used at the same time.
- Report any issues via [GitHub Issues](https://github.com/bisfranz/SporeNEXT/issues) or PM me on Discord.

### Installation

1. Download the latest version of the launcher from the [Releases](https://github.com/bisfranz/SporeNEXT/releases) section and install it by running the installer.
2. Before launching Spore NEXT, run Spore: Galactic Adventures at least once. Spore NEXT uses the Windows Registry to detect the game's installation path automatically.
3. Once installed, you can create an account and sign in using multiple authentication methods, or use Spore NEXT in Offline Mode with certain features unavailable.
